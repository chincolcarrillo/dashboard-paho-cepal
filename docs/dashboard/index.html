Inicio

El dashboard analiza el comercio internacional de medicamentos, otras tecnologías sanitarias, dispositivos médicos e insumos en América Latina y el Caribe a partir de los datos de CEPII-BACI, con nomenclatura HS 2007.

Los productos se clasificaron en categorías de uso común en la industria, cada una cuenta con una pestaña independiente en el dashboard:
